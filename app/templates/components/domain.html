{# Cómo se muestran los valores de enum que guarda la base. El problema que resuelve: las columnas guardan strings en inglés y en minúscula (`meal_type='breakfast'`, `context='restaurant'`), y las plantillas los mostraban con `{{ event.meal_type | title }}` o, en el mejor caso, con `{{ _(event.meal_type | title) }}` — que le pide al catálogo un msgid que ningún `pybabel extract` puede encontrar, porque no es un literal. Resultado: los enums se veían siempre en inglés, y el color de cada tipo de comida estaba escrito de nuevo (y distinto) en cada pantalla que los mostraba. Acá el valor de la base se traduce contra literales de verdad y se le asigna un tono una sola vez, así que Home, la lista de comidas, el detalle y el historial dicen lo mismo con el mismo color. Uso: los macros son globals del entorno (`app/web/helpers.py`), igual que `ui` e `ic`, así que no hace falta ningún `{% import %}`: {{ dm.meal_badge(meal.meal_type) }} {{ dm.quantity(item.quantity, item.unit) }} Un valor que no esté en el mapa cae en un rótulo genérico en vez de romper: la columna es un `String(30)` sin restricción, así que el NLP puede escribir cualquier cosa ahí. #} {% import 'components/ui.html' as ui %} {% import 'components/icons.html' as ic %} {#- ── Tipo de comida ────────────────────────────────────────────────────────── Los tonos siguen el arco del día (mañana ámbar, mediodía azul, noche violeta) y `snack` queda en verde por descarte, no por semántica. -#} {% macro meal_type_label(meal_type) -%} {%- set labels = { 'breakfast': _('Breakfast'), 'lunch': _('Lunch'), 'dinner': _('Dinner'), 'snack': _('Snack'), 'other': _('Meal'), } -%} {{- labels.get(meal_type, _('Meal')) -}} {%- endmacro %} {% macro meal_badge(meal_type, size='sm') -%} {%- set tones = {'breakfast': 'warn', 'lunch': 'info', 'dinner': 'brand', 'snack': 'ok'} -%} {{ ui.badge(meal_type_label(meal_type), tone=tones.get(meal_type, 'neutral'), size=size) }} {%- endmacro %} {#- ── Dónde se comió ────────────────────────────────────────────────────────── Devuelve solo el texto: quien llama decide si lo pone al lado de un ícono, en una tarjeta o en una lista. -#} {% macro meal_context_label(context) -%} {%- set labels = { 'home': _('At home'), 'outside': _('Out'), 'travel': _('Travelling'), 'restaurant': _('Restaurant'), 'other': _('Somewhere else'), } -%} {{- labels.get(context, context | title) -}} {%- endmacro %} {#- ── Tipo de entrenamiento ─────────────────────────────────────────────────── La v1 pintaba cada tipo con una paleta distinta (`bg-blue-100`, `bg-orange-100`, `bg-violet-100`, `bg-teal-100`, `bg-sky-100`): cinco familias de color que el modo oscuro no puede seguir. Acá todos caen en los tokens, y el default es `move` — el acento de dominio del movimiento — para que un tipo que el NLP invente igual se vea como un entrenamiento y no como texto gris. -#} {% macro workout_type_label(workout_type) -%} {%- set labels = { 'gym': _('Gym'), 'home': _('At home'), 'outdoor': _('Outdoors'), 'cardio': _('Cardio'), 'sports': _('Sports'), 'yoga': _('Yoga'), 'other': _('Workout'), } -%} {{- labels.get(workout_type | lower if workout_type else 'other', workout_type | title) -}} {%- endmacro %} {% macro workout_badge(workout_type, size='sm') -%} {%- set tones = {'gym': 'move', 'home': 'brand', 'outdoor': 'ok', 'cardio': 'warn', 'sports': 'info', 'yoga': 'body'} -%} {{ ui.badge(workout_type_label(workout_type), tone=tones.get(workout_type | lower if workout_type else '', 'move'), icon='bolt', size=size) }} {%- endmacro %} {#- ── Categoría de alimento ─────────────────────────────────────────────────── `FoodItem.category` guarda los nueve valores en minúscula que siembra `seed.py` (`vegetable`, `grain`, `processed`…). La despensa los mostraba con `_(item.food_item.category | title)`, que además de ser inextraíble le pedía al catálogo "Vegetable" — un msgid que no existe. -#} {% macro food_category_label(category) -%} {%- set labels = { 'vegetable': _('Vegetables'), 'fruit': _('Fruit'), 'protein': _('Protein'), 'grain': _('Grains'), 'dairy': _('Dairy'), 'fat': _('Fats'), 'beverage': _('Drinks'), 'processed': _('Packaged'), 'other': _('Other'), } -%} {{- labels.get(category | lower if category else 'other', category | title) -}} {%- endmacro %} {#- ── Movimiento de despensa ────────────────────────────────────────────────── Cuatro tipos, cada uno con su ícono y su tono. La v1 los rotulaba con `m.movement_type|title` (siempre en inglés) y los ilustraba con emoji (🛒🍽️🗑️📝), que no siguen el peso de la tipografía ni el tema. -#} {% macro movement_type_label(movement_type) -%} {%- set labels = { 'purchase': _('Purchase'), 'consumption': _('Used'), 'discard': _('Thrown out'), 'adjustment': _('Adjusted'), } -%} {{- labels.get(movement_type | lower if movement_type else '', movement_type | title) -}} {%- endmacro %} {% macro movement_icon(movement_type, class='w-4 h-4') -%} {%- set icons = {'purchase': 'cart', 'consumption': 'meal', 'discard': 'x', 'adjustment': 'pantry'} -%} {%- set tones = {'purchase': 'ok', 'consumption': 'food', 'discard': 'danger', 'adjustment': 'stock'} -%} {%- set key = movement_type | lower if movement_type else '' -%} {{ ic.icon(icons.get(key, 'pantry'), class) }} {%- endmacro %} {#- ── Cantidad ──────────────────────────────────────────────────────────────── `quantity` es `Numeric`, así que llega como `Decimal`: sin esto una porción de 2 se mostraba como "2.00". Los enteros se muestran enteros y el resto con un decimal, que es toda la precisión que tiene sentido en "1.5 kg de pollo". -#} {% macro quantity(value, unit=None) -%} {%- if value is not none -%} {%- set num = value | float -%} {{- num | int if num == num | int else num | round(1) -}} {%- if unit %} {{ unit }}{% endif -%} {%- endif -%} {%- endmacro %}
